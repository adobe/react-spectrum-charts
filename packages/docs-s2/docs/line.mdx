# Line

<StageBadge />

Line charts show how values change over time. Each series becomes a line through its data points,
plotted by `dimension` on the x-axis and `metric` on the y-axis.

<LinePlayground />

## Data

`data` goes on `Chart` as an array of objects, one per point. On `Line`, `dimension` names the
x-axis field (default `datetime`), `metric` names the y-axis field (default `value`), and `color`
names the field that splits the rows into series. Without `color`, every row belongs to one line.
Time values are milliseconds since the epoch. Most examples on this page use `lineTrafficData`:

<DataCode name="lineTrafficData" />

```tsx
<Chart data={lineTrafficData}>
  <Axis position="bottom" labelFormat="time" baseline ticks />
  <Axis position="left" grid />
  <Line color="series" />
</Chart>
```

### Empty and loading

When `data` is an empty array, `Chart` shows `emptyStateText` instead of the plot. Set `loading` on
`Chart` to show a spinner while data loads.

<LineStatesPlayground />

## Lines

### Series

`color`, `lineType`, and `opacity` each take either a data field or a fixed value such as
`{ value: 'dashed' }`. A field gives each series its own color, dash pattern, or opacity from the
chart's `colors`, `lineTypes`, and `opacities` lists. `color` defaults to a single categorical color
and `lineType` to solid.

<LineSeriesPlayground />

### interpolate

`interpolate` sets the curve between points. The default, `linear`, draws straight segments.

- `monotone` draws a smooth curve that never overshoots the data.
- `basis`, `cardinal`, `catmull-rom`, and `natural` draw other kinds of splines. `basis` doesn't
  pass through the data, so it draws no points.
- `step`, `step-before`, and `step-after` draw horizontal and vertical steps, with the vertical step
  centered between points, at the start of each interval, or at the end.

<LineInterpolatePlayground />

### gradient

`gradient` fills the area under the line with its color, fading to transparent at the bottom. The
gradient only draws when the chart has a single line. `opacity` fades the line and its gradient
together.

<LineGradientPlayground />

### Size

Stroke width, point size, and hover rings scale with the chart's width: a chart under 400px wide
uses the small size, one under 800px the medium size, and anything wider the large size. Use
`width`, `height`, `minWidth`, and `maxWidth` on `Chart` to constrain it. Drag the width below 400
to see the small size.

<LineSizePlayground />

## Points

### staticPoint

Points are hidden until hovered. `staticPoint` names a boolean field; rows where it's exactly `true`
always show a point. Points scale with the chart; set `pointSize` to fix their area in square
pixels.

<DataCode name="lineMilestoneData" />

<LinePointPlayground />

### Sparklines

`isSparkline` with `isMethodLast` draws a point on the last row of the data. The sparkline shown
has no axes and is 200 × 60px.

<LineSparklinePlayground />

## Segments

### Alternate segments

`alternateSegmentKey` names a boolean field. Rows where it's truthy draw in
`alternateSegmentLineType` (default `dotted`), for example to mark estimated or incomplete values.

<DataCode name="lineEstimatedData" />

<LineSegmentPlayground />

### primarySeries

`primarySeries` keeps some series in color and draws the rest in gray. Pass a number N to keep
the first N series in color order (`2` keeps the first two), or a list of series names.
`otherSeriesColor` changes the gray (default `gray-400`) to another Spectrum 2 color token. Gray
series don't get `LineDirectLabel` labels.

<LinePrimarySeriesPlayground />

:::note
Don't combine `alternateSegmentKey` with `LineForecast`. The line then ignores the forecast's
`metric` field and dashes only the rows flagged by `alternateSegmentKey`, though the forecast's
boundary rule and label still draw. `primarySeries` works with either one.
:::

## Scales

### scaleType

`scaleType` sets the x scale. `time` (the default) is for timestamps, and `linear` for other
numeric values such as minutes. Both keep the gaps between values to scale. `point` spaces ordered
categories such as weekdays evenly; use it only when the x values aren't times or numbers.

<LineScaleTypePlayground />

### padding

`padding` adds space between the plot edges and the first and last points. Its unit depends on
`scaleType`:

- `time` and `linear`: pixels. The default is `0`, so the line touches both edges.
- `point`: a ratio of the step between points, from 0 to 1. The default is `0.5`.

This example uses a time scale.

<LinePaddingPlayground />

### dualMetricAxis

`dualMetricAxis` compares the trends of two series whose values are far apart. On a shared y-axis,
the smaller series, here purchases, is flattened near zero. `dualMetricAxis` plots the last series
against its own y-scale, shown by an `Axis` with `position="right"`, so you can see purchases fall
while visits rise. Turn it off to see the shared scale, where the right axis isn't needed.

The right axis labels take the color of the last series. When there are only two series, the left
axis labels take the color of the first.

<DataCode name="lineDualAxisData" />

<LineDualAxisPlayground />

## Hover

Lines respond to the pointer when they have `ChartInspect`, `ChartPopover`, `ChartActionBar`,
`onClick`, or `onContextMenu`. Hovering fades the other series, rings the hovered point, and shows
its value next to it.

- `interactionMode="nearest"` (the default) picks the point closest to the pointer anywhere in the
  plot. `item` picks a point only when the pointer is over it.
- `dimensionHover` highlights every series at the hovered x value and labels each of them.
- `showHoverLabel={false}` hides the value label. `ChartInspect` always hides it, since the inspect
  dialog shows the value. Set `hoverLabelKey` to show another field, such as a pre-formatted string.

<LineHoverPlayground />

## Metric ranges

`metricRanges` shades a band between two fields, such as the confidence interval of a forecast.
Each object needs `metricStart` and `metricEnd`, and draws its own dashed line through `metric`
(default `value`). This example pairs a range with [`LineForecast`](#lineforecast): the range's
`metric` is the forecast field, and the band starts at the last actual value, where `low` and `high`
equal `value`.

- `rangeOpacity` sets the band's opacity (default `0.2`).
- `lineType` and `lineWidth` style the range's line (default `dashed` and `S`).
- `displayOnHover` shows the range only while its series is hovered.
- `scaleAxisToFit` stretches the y-axis to include the whole band.

<DataCode name="lineRangeData" />

<LineMetricRangePlayground />

:::note
A metric range's `metric` defaults to `value`, not to the parent line's `metric`. Set it when your
line uses another field.
:::

## LineDirectLabel

`LineDirectLabel` labels each line at the right edge of the plot, which can replace a legend.
Labels are colored like their series and spread apart when they would overlap.

- `value` chooses the text: the `last` value (the default), the `average`, or the `series` name.
- `position="start"` moves labels to the left edge and labels the first value instead.
- `format` is a [d3-format](https://d3js.org/d3-format) specifier for numeric values (default
  `,.2~f`). `prefix` adds text before the value.
- `excludeSeries` skips the listed series.

<LineDirectLabelPlayground />

## LineForecast

`LineForecast` continues a line with forecast values. Put the forecast in its own field, `metric`,
and leave the line's `metric` empty for those rows. `start` is the x value (a timestamp on a time
scale) where the forecast begins. From there on the line uses `alternateSegmentLineType` (default
`dotted`), and a vertical rule marks the boundary with `label` (default `Forecast`).

<LineForecastPlayground />

## Axes

Line charts usually have a bottom `Axis` with `labelFormat="time"` and a left `Axis` with `grid`.
Time labels follow the axis `granularity`, and number labels follow `numberFormat` (default
`shortNumber`). Both use the chart's `locale`, which also applies to `ChartInspect`.

Add `ReferenceLine` inside the left `Axis` to mark a value, such as a target. See
[Axis](./axis.mdx) for every axis and reference line option.

<LineAxisPlayground />

## Legend

Add `Legend` as a sibling of `Line` to list the series.

- `isToggleable` lets users click an entry to hide or show its series.
- `highlight` highlights a series while its entry is hovered.

<LineLegendPlayground />

### Hiding series

`hiddenSeries` on `Chart` hides series from outside the chart, for example from a filter control.
To start with series hidden but let users toggle them, set `defaultHiddenSeries` on a toggleable
`Legend` instead.

<LineHiddenSeriesPlayground />

## Interaction

### ChartInspect and ChartPopover

Add `ChartInspect` to show details on hover and `ChartPopover` to show details on click. Pass a
function as children to render your own content.

- `highlightBy` on `ChartInspect` sets what stays in color while inspecting: the hovered `item`
  (the default), its whole `series`, or every point at the same x value (`dimension`).
- `rightClick` on `ChartPopover` opens it on right-click instead of click.

<LineInteractionPlayground />

`onClick` and `onContextMenu` on `Line` run a callback with the clicked point's data.
`ChartActionBar` shows actions for a selected point; see [ChartActionBar](./chart-action-bar.mdx).
See [Interaction](./interaction.mdx) for every `ChartInspect` and `ChartPopover` option.

### Highlighting

`highlightedSeries` on `Chart` highlights a series from outside the chart, for example from a
table row. `highlightedItem` highlights points by row ID and can take a list; set `idKey` on
`Chart` to the field it matches. In this example `idKey` is `datetime`, so one date highlights a
point on every series.

<LineHighlightPlayground />

## Animation

The chart's `animationTypes` lists which animations play. By default, `hover` eases the other
lines in and out of their faded state when you hover a line, and `drawIn` sweeps the lines in from
left to right over 850ms when the chart mounts; static points appear as the sweep passes them.
Draw-in works on time, linear, and point scales.

<LineAnimationPlayground />

Set `animationTypes={['hover']}` to turn off draw-in only, or `animations={false}` to turn off all
animation. See [Animation](./guides/animation.mdx) for when draw-in replays.
