# Title

<StageBadge />

`Title` adds a title to a chart. Add it as a child of `Chart`, alongside the marks; it works with
every chart type.

<TitlePlayground />

## Data

`Title` doesn't read the chart's data. The examples on this page use a `Bar` chart of `browserData`:

<DataCode name="browserData" />

```tsx
<Chart data={browserData}>
  <Title text="Visitors by browser" />
  <Bar dimension="browser" metric="count" />
</Chart>
```

## Placement

- `orient` picks the side of the chart the title is on: `top` (default), `bottom`, `left`, or
  `right`. Left and right titles are rotated to read along the side.
- `position` aligns the title along that side: `start` (default), `middle`, or `end`. On a top
  or bottom title, `start` is the left edge of the plot.

The title is aligned to the plot area, not the whole chart, so a `start` title lines up with the
left edge of the plot rather than the axis labels.

<TitlePlacementPlayground />

## Font

`fontWeight` and `fontSize` set the title's text style. The defaults are `700` and `24`. Any
CSS font weight works, such as `400`, `'normal'`, or `'bold'`.

<TitleFontPlayground />

## Size

The title takes space from the chart, so the plot shrinks to fit it. A larger `fontSize`, or a
title on the left or right, leaves less room for the plot.

## Chart title prop

`title` on `Chart` also draws a title, using a smaller theme style you can't change. A `Title`
child replaces it. Use `Title` when you need to set the title's placement or font.

<ChartTitlePlayground />

:::note
A chart shows one title. If there's more than one `Title`, only the first is used. Subtitles,
title color, and the spacing between the title and the plot aren't supported.
:::
