# ChartActionBar

<StageBadge />

`ChartActionBar` shows a toolbar of actions, like annotating or bookmarking, when a user clicks a
point on a `Line`. Add it as a child of `Line`; click a point in the chart below to open it.

<ChartActionBarPlayground />

`ChartActionBar` is a lab component. Import it from the `lab` subpath:

```tsx
import { Axis, Chart, Line } from '@spectrum-charts/react-spectrum-charts-s2';
import { ChartActionBar } from '@spectrum-charts/react-spectrum-charts-s2/lab';
```

## Data

`ChartActionBar` doesn't need any data fields of its own. It passes the clicked point to your
actions as `datum`, which holds every field of that row (here `datetime`, `device`, and
`visits`). The examples on this page use `deviceVisitsData`:

<DataCode name="deviceVisitsData" />

## Actions

`children` is a function that takes the clicked `datum` and a `close` function and returns an
array of action elements. Use React Spectrum `ActionButton`s with `isQuiet`, and give each one a
`key`. Call `close` when an action finishes to dismiss the bar.

```tsx
import { ActionButton, Text } from '@react-spectrum/s2';
import StickyNote from '@react-spectrum/s2/icons/StickyNote';

<Chart data={deviceVisitsData}>
  <Line metric="visits" color="device">
    <ChartActionBar>
      {(datum, close) => [
        <ActionButton
          key="annotate"
          isQuiet
          onPress={() => {
            addNote(datum.device, datum.datetime);
            close();
          }}
        >
          <StickyNote />
          <Text>Annotate</Text>
        </ActionButton>,
      ]}
    </ChartActionBar>
  </Line>
</Chart>;
```

Actions can be any element, such as a `MenuTrigger` for a menu of related actions or a
`ContextualHelp` with details about the point. If `children` isn't set, clicking a point doesn't
open a bar.

### maxActions

The bar shows up to `maxActions` actions inline (default `4`). The rest move to a **More
actions** (`···`) menu at the end of the bar. The bar is at most 800px wide, so it also moves
actions into the menu when they don't fit.

<ChartActionBarOverflowPlayground />

### isEmphasized

`isEmphasized` gives the bar an accent background. Set `staticColor="white"` on the actions so
they stay readable on it.

<ChartActionBarEmphasizedPlayground />

## Placement and dismissing

The bar opens just above the clicked point. When there isn't room above, it opens below, and it
always stays inside the window. Users can move the bar by dragging the
handle at its left end, or by focusing the handle and pressing the arrow keys.

Focus moves into the bar when it opens. The bar closes when the user presses Escape, clicks
outside it, or runs an action that calls `close`. Focus then returns to where it was.
`onClearSelection` is called each time the bar closes, for example to clear selection state you
keep outside the chart.

```tsx
<ChartActionBar onClearSelection={() => setSelectedPoint(undefined)}>{actions}</ChartActionBar>
```

## Line

`ChartActionBar` works as a child of `Line` and opens on click; right-clicking a point doesn't
open it. The clicked point stays marked while the bar is open.

### ChartInspect and ChartPopover

`ChartInspect` works alongside the action bar. Its tooltip is hidden while the bar is open.

A `Line` can't open both a `ChartPopover` and a `ChartActionBar` on click. To use both, set
`rightClick` on `ChartPopover` so it opens on right-click and the action bar opens on click.

<ChartActionBarSiblingsPlayground />

:::note
`ChartActionBar` is only supported on `Line`.
:::
