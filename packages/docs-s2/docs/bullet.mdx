# Bullet

<StageBadge />

Bullets compare a metric against a target. Each data point becomes one bullet: a bar for the
metric, a line for the target, and a label with the formatted value.

<BulletPlayground />

`Bullet` is a lab component. Import it from the `lab` subpath:

```tsx
import { Chart } from '@spectrum-charts/react-spectrum-charts-s2';
import { Bullet } from '@spectrum-charts/react-spectrum-charts-s2/lab';
```

## Data

`data` goes on `Chart` as an array of objects, one per bullet. On `Bullet`, `metric` names the
field for the bar (default `currentAmount`), `target` names the field for the target line (default
`target`), and `dimension` names the field for each bullet's label (default `graphLabel`). Most
examples on this page use `bulletScoreData`:

<DataCode name="bulletScoreData" />

```tsx
<Chart data={bulletScoreData}>
  <Bullet metric="score" dimension="kpi" target="goal" />
</Chart>
```

All bullets in a chart share one scale, so their bars and targets can be compared directly. Use
separate charts for metrics in different units.

### Empty and loading

When `data` is an empty array, `Chart` shows `emptyStateText` instead. Set `loading` on `Chart` to
show a spinner while data loads.

<BulletStatesPlayground />

## Layout

`direction` stacks bullets in a `column` (the default) or places them side by side in a `row`.

In a column, `labelPosition="side"` moves each bullet's label to its left and its value to its
right, so bullets take less height. Rows always show labels on top.

<BulletLayoutPlayground />

The examples on this page are 480px wide and exactly as tall as their bullets. Bullets keep a fixed
height and spacing, so a taller `Chart` leaves empty space below them rather than stretching them.

## Target

`showTarget` draws the target line (on by default). `showTargetValue` adds the target value below
the line, formatted like the metric value. A data point without a target has no target line, and its
target value reads "No Target".

<BulletTargetPlayground />

## Scale

The scale always starts at 0. `scaleType` sets its maximum:

- `normal` (default) fits the data: the largest metric or 105% of the largest target.
- `fixed` uses `maxScaleValue`. Bars and targets beyond it stop at the end of the scale.
- `flexible` uses `maxScaleValue` until the data needs more room, then fits the data.

`maxScaleValue` defaults to `100`, which suits percentages and scores. `metricAxis` adds a value
axis below the bullets.

<BulletScalePlayground />

:::note
`metricAxis` only applies to column bullets and isn't shown with `showTargetValue`. Bullets draw
their own labels and axis; they don't use `Axis` or `Legend`.
:::

## Thresholds and track

`thresholds` draws background bands behind each bar, such as red, orange, and green performance
zones. Each band takes a `fill` CSS color and optional `thresholdMin` and `thresholdMax`; an
omitted bound extends the band to the edge of the scale. Bands are drawn at 20% opacity.

<DataCode name="bulletScoreThresholds" />

- `thresholdBarColor` colors each bar with the full-strength `fill` of the band its value falls in.
  Values below the first band keep `color`.
- `track` draws a plain gray track behind each bar instead. It's ignored when `thresholds` is set.

<BulletThresholdsPlayground />

## Color

`color` sets the bar color as a Spectrum color name, such as `purple-900`, or a CSS color. The
default is `blue-900`. Target lines and labels are always gray.

## Labels and number format

### numberFormat

`numberFormat` formats the metric values, target values, and metric axis. It accepts
`standardNumber` (default), `shortNumber`, `currency`, `shortCurrency`, or a
[d3-format](https://d3js.org/d3-format) specifier. Numbers follow the chart's `locale`.

<DataCode name="bulletRevenueData" />

<BulletNumberFormatPlayground />

### metricLabel and targetLabel

To show text you've already formatted, such as values with units, set `metricLabel` to a field
holding the metric text and `targetLabel` to a field holding the target text. `targetLabel` only
shows with `showTargetValue`.

## Title

Add [`Title`](./title.mdx) as a sibling of `Bullet` to label the chart. The main example at the top
of this page has one.

## Interaction

### ChartInspect

Add `ChartInspect` with a function as children to show details when a bullet is hovered. The
function receives the bullet's data row. Hovering the bar or target line shows the details; with
`thresholds` or `track`, hovering anywhere along the band does too.

<BulletInspectPlayground />

:::note
Bullets don't support `ChartPopover` or highlighting (`highlightedSeries`, `highlightedItem`)
yet, and `ChartInspect` without children shows nothing.
:::

## Animation

Bullets don't animate; `animationTypes` has no effect on them.

## API

### Bullet

`name` identifies the bullet's marks and signals in the rendered Vega spec. It defaults to
`bullet0`, `bullet1`, and so on.
