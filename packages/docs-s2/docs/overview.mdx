# React Spectrum Charts for Spectrum 2

`@spectrum-charts/react-spectrum-charts-s2` is React Spectrum Charts built on
[Spectrum 2](https://react-spectrum.adobe.com/). You describe a chart as a tree of components, like
`Chart`, `Axis`, `Line`, and `Legend`, and the library draws it with Spectrum 2 colors, type, and
interactions.

If you use `@adobe/react-spectrum-charts` today, see
[Migrating from S1](./guides/migrating-from-s1.mdx).

## Your first chart

`Chart` holds the data. Its children name the fields to draw: here, `visits` per `date`, with a
line per `device`.

```bash
npm install @spectrum-charts/react-spectrum-charts-s2
```

See [Getting started](./guides/getting-started.mdx) for peer dependencies and setup.

## Components

- [Chart](./chart.mdx): the container for every chart.
- Charts: [Line](./line.mdx), [Bar](./bar.mdx), and [Donut](./donut.mdx).
- Lab charts: [Area](./area.mdx), [Bullet](./bullet.mdx), [Combo](./combo.mdx), and
  [Scatter](./scatter.mdx).
- [Axis](./axis.mdx), [Legend](./legend.mdx), and [Title](./title.mdx).
- [ChartInspect and ChartPopover](./interaction.mdx): details on hover and click.
- [ChartActionBar](./chart-action-bar.mdx) (lab): actions for a selected point.
