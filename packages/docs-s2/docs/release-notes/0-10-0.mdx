# 0.10.0

This release turns on animation by default, makes Donut an alpha component, and ships the package
as ES modules for smaller bundles. It includes breaking changes; see
[Upgrading to 0.10.0](../guides/upgrading-to-0-10-0.mdx) for the code changes.

## Breaking changes

- **ESM only.** The package ships as ES modules and requires Node `>=20.19.0`.
- **New peer dependency.** `react-aria-components` `^1.14.0`.
- **Entry points.** `Donut`, `DonutSummary`, and `SegmentLabel` move to the package root. The
  `pre-alpha` entry point is renamed `lab`, and `ChartActionBar` is imported from `lab`.
- **Donut.** `startAngle` and `otherItemColor` are removed.

## Highlights

- **Smaller bundles.** The package no longer bundles its own copies of React Spectrum S2, React
  Aria, or Vega, so it adds about half as much to an app that already uses React Spectrum S2.
- **Animation on by default.** Lines, bars, donuts, and combos draw in when the chart mounts, and
  hover fades animate, following Spectrum 2 motion. Draw-in plays once per mount. See
  [Animation](../guides/animation.mdx).
- **Reduced motion.** When the user prefers reduced motion, draw-in is skipped and hover fades
  still play.
- **Donut is alpha.** See [Stages and lab](../guides/stages-and-lab.mdx).
- **ChartActionBar (lab).** A floating toolbar of actions for a clicked line point. See
  [ChartActionBar](../chart-action-bar.mdx).

## Changed defaults

- Top and bottom legends align to the start of the chart instead of the center.
- Donut segments are sorted largest first. Set `sortOrder="data"` to keep data order.
- `Chart` props set to `undefined` fall back to their defaults.

## Bar

- `BarDirectLabel` follows each bar in stacked and dodged bars, and hides labels that overlap or
  don't fit. New `overflow` and `dataKey` props. See [BarDirectLabel](../bar.mdx#bardirectlabel).
- Better keyboard and screen reader support: dodged bars can be focused, focused bars and groups
  are described by their values, and Shift+Tab returns to the last focused bar.
- Fixed `highlightedItem`, `ChartInspect` group highlighting, and short-number label formats.

## Donut

- `ChartInspect` and `ChartPopover` show the segment's color, name, share, and value when they have
  no children. See [Default content](../interaction.mdx#default-content).
- Hovering a segment shows its label, even when the label was hidden to avoid overlap.
- Ring thickness, label spacing, and donut size scale with the chart size, and side legends stay
  next to the donut.
- Semicircle `DonutSummary` deltas sit inside the arc, and summary text that would truncate
  completely is hidden.
- Fixed label overlap, tiny segments, and donuts growing or shifting on resize.

## Line

- Fixed hover with `interactionMode="item"`, series highlighting, single-series lines, and
  `interpolate="basis"`.
- Fixed charts collapsing or flickering with fixed metric-axis ranges or when every series is
  hidden.

## Axis and reference lines

- Reference lines outside the axis range no longer collapse the chart.
- A right axis lines up with a gridded left axis.

## Lab charts

- **Area**, **Bullet**, and **Scatter**: fixes for `highlightedItem`, hidden or missing targets,
  and outlines.
- **Combo** respects the chart's `animations` and `animationTypes`.

## Performance and stability

- Charts render once when first displayed instead of twice, and hover animations stay smooth on
  charts with many points or series.
- Off-screen and idle charts do no animation work.
- A chart with no children logs an error instead of throwing.
