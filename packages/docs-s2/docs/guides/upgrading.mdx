# Upgrading

<SkillExport
  name="upgrade-react-spectrum-charts-s2"
  description="Upgrade @spectrum-charts/react-spectrum-charts-s2 from an earlier 0.x release to the latest version. Use when bumping the package version or fixing imports, peer dependencies, Node version, or props removed in a 0.x release."
/>

This page lists the code changes that keep your charts building and working when you upgrade
`@spectrum-charts/react-spectrum-charts-s2`: breaking changes, removed or renamed props, and peer
dependency and Node version bumps. It also lists changed defaults. Bug fixes and new features that
need no code changes are left out; see the release notes ([0.11.0](../release-notes/0-11-0.mdx),
[0.10.0](../release-notes/0-10-0.mdx)) for those.

Find the section for the version you're on, then apply it and every section above it. For
example, from 0.8.0, apply [From 0.8.0](#from-080), [From 0.9.0](#from-090), and
[From 0.10.0](#from-0100).

Coming from `@adobe/react-spectrum-charts` instead? See [Migrating from S1](./migrating-from-s1.mdx).

## Changed defaults

Each changed default is marked **Changed default** and says what's new, what it was, and whether
you can keep the old behavior. The new defaults are the recommended Spectrum 2 behavior. Don't
override them just to keep a chart looking the same as before.

If you're an agent applying this guide:

- Don't keep an old default on your own.
- If a changed default can be turned off, tell the user what changed and ask whether to adopt the
  new default (recommended) or keep the old behavior. Change the code only to match their answer.
- If a changed default can't be turned off, tell the user what changed. Don't ask, and don't try to
  work around it.

## From 0.10.0

### Node version

Node `>=22.12.0` is required. Installs on Node 20 fail with an engine error. No code changes are
needed.

```bash
yarn add @spectrum-charts/react-spectrum-charts-s2@latest
```

## From 0.9.0

### ESM only

The package ships as ES modules only (`"type": "module"`). `require()`, the UMD global, and
imports from inside `dist/` no longer work. Import from the package entry points instead.

```ts
// Before
const { Chart } = require('@spectrum-charts/react-spectrum-charts-s2');

// After
import { Chart } from '@spectrum-charts/react-spectrum-charts-s2';
```

Jest must transform `@spectrum-charts/*` and stub CSS imports. See
[Testing and troubleshooting](./testing-and-troubleshooting.mdx#jest).

### Node and peer dependencies

- Node `>=20.19.0` is required.
- `react-aria-components` `^1.14.0` is a new peer dependency.

```bash
yarn add @spectrum-charts/react-spectrum-charts-s2@latest react-aria-components@^1.14.0
```

### Entry points

The `@spectrum-charts/react-spectrum-charts-s2/pre-alpha` entry point is renamed `@spectrum-charts/react-spectrum-charts-s2/lab`, and `Donut`, `DonutSummary`, and
`SegmentLabel` move to `@spectrum-charts/react-spectrum-charts-s2`. The `alpha` and `beta` subpaths are removed; they never pointed at published
files. See [Stages and lab](./stages-and-lab.mdx).

| Component                                                                                                    | 0.9.0 import                                          | 0.10.0 import                                   |
| ------------------------------------------------------------------------------------------------------------ | ----------------------------------------------------- | ----------------------------------------------- |
| `Donut`, `DonutSummary`, `SegmentLabel`                                                                      | `@spectrum-charts/react-spectrum-charts-s2/pre-alpha` | `@spectrum-charts/react-spectrum-charts-s2`     |
| `Area`, `Bullet`, `Combo`, `Scatter`, `ScatterAnnotation`, `ScatterPath`, `Trendline`, `TrendlineAnnotation` | `@spectrum-charts/react-spectrum-charts-s2/pre-alpha` | `@spectrum-charts/react-spectrum-charts-s2/lab` |

```ts
// Before
import { Donut, DonutSummary, Scatter, ScatterPath } from '@spectrum-charts/react-spectrum-charts-s2/pre-alpha';

// After
import { Donut, DonutSummary } from '@spectrum-charts/react-spectrum-charts-s2';
import { Scatter, ScatterPath } from '@spectrum-charts/react-spectrum-charts-s2/lab';
```

### Donut

`startAngle` and `otherItemColor` are removed. For a half donut, use `variant="semicircle"`. See
[Semicircle](../donut.mdx#semicircle).

```tsx
// Before
<Donut metric="count" color="browser" startAngle={-Math.PI / 2} otherItemColor="gray-300" />

// After
<Donut metric="count" color="browser" />
```

**Changed default: segment order.** Segments are sorted largest-first. They were in data order.
Boolean donuts still use data order. See [Semicircle](../donut.mdx#semicircle).

- Keep the old behavior: set `sortOrder="data"`, for example for ordered categories like survey
  responses.

```tsx
<Donut metric="count" color="response" sortOrder="data" />
```

**Changed default: inspect and popover content.** `ChartInspect` and `ChartPopover` on a `Donut`
show the segment's color, name, share, and value when they have no children. They were empty. See
[Default content](../interaction.mdx#default-content).

- Keep the old behavior: not possible. To show your own content instead, pass children.

### Bar

**Changed default: hover animation.** Bar hover fades animate, like Line and Donut. They were
instant.

- Keep the old behavior: leave `'hover'` out of `animationTypes`, or set `animations={false}`.
  Either one also turns off hover animation for the other marks in the chart.

**Changed default: BarDirectLabel visibility.** Labels outside the bar are hidden when they would
overlap a bar or another label. Labels inside the bar that don't fit are hidden, except at
`position="start"`, where they move outside the bar tip. All labels used to show. See
[BarDirectLabel](../bar.mdx#bardirectlabel).

- Keep the old behavior for labels inside the bar: set `overflow="spill"` to move them outside
  instead of hiding them.
- Keep the old behavior for labels outside the bar: not possible.

### Legend alignment

**Changed default.** Top and bottom legends align to the start of the chart, matching Spectrum 2.
They were centered. See [Position and alignment](../legend.mdx#position-and-alignment).

- Keep the old behavior: set `align="middle"` on `Legend`.

### Undefined Chart props

`Chart` props explicitly set to `undefined` now fall back to their defaults instead of overriding
them. Code like `height={settings.height}` now gets the default `height` when `settings.height` is
missing. If you relied on `undefined` overriding a default, pass the value you want instead.

### Draw-in

**Changed default.** `animationTypes` defaults to `['hover', 'drawIn']`, so lines, bars, donuts,
and combos animate in when the chart mounts. Draw-in plays once per mount; re-renders and data
updates don't replay it. Charts used to appear without drawing in. See [Animation](./animation.mdx).

- Keep the old behavior: set `animationTypes={['hover']}`.

```tsx
<Chart data={data} animationTypes={['hover']}>
```

### Reduced motion

**Changed default.** Charts now honor the user's reduced-motion setting: draw-in is skipped and
hover animation still plays. The setting used to be ignored. See
[Animation](./animation.mdx#reduced-motion).

- Keep the old behavior: not possible. To turn off hover animation as well, set
  `animations={false}`.

## From 0.3.0

### Peer dependencies

0.4.0 replaced `@adobe/react-spectrum` with `@react-spectrum/s2` `>=1.0.0`. Charts render their
own S2 `Provider`, so build `ChartInspect` and `ChartPopover` content with `@react-spectrum/s2`
components.

```bash
yarn remove @adobe/react-spectrum
yarn add @react-spectrum/s2
```

### ChartTooltip → ChartInspect

`ChartTooltip` is renamed `ChartInspect`. Props and the children function are the same. Types are
renamed too: `ChartTooltipProps` → `ChartInspectProps`, `ChartTooltipElement` →
`ChartInspectElement`, and `TooltipHandler` → `InspectHandler`. See
[ChartInspect](../interaction.mdx#chartinspect).

```tsx
// Before
import { ChartTooltip } from '@spectrum-charts/react-spectrum-charts-s2';

<Line dimension="datetime" metric="value">
  <ChartTooltip>{(datum) => <div>{datum.value}</div>}</ChartTooltip>
</Line>

// After
import { ChartInspect } from '@spectrum-charts/react-spectrum-charts-s2';

<Line dimension="datetime" metric="value">
  <ChartInspect>{(datum) => <div>{datum.value}</div>}</ChartInspect>
</Line>
```

### Chart theme

The `theme` prop on `Chart` is removed. Use `colorScheme`. See
[Color and theme](../chart.mdx#color-and-theme).

```tsx
// Before
<Chart data={data} theme={darkTheme} colorScheme="dark">

// After
<Chart data={data} colorScheme="dark">
```

### Line size

**Changed default.** Line stroke width, point size, and hover rings scale with the chart's width.
They were fixed. Check your charts at the sizes you use. See [Size](../line.mdx#size).

- Keep the old behavior: not possible.

## From 0.2.0

### React 19

0.3.0 raised the `react` and `react-dom` peer dependencies to `>=19.0.0`. Upgrade React before
upgrading the package.

Skip 0.3.0 itself, which was published without its build output. Use 0.3.2 or later.

## From 0.1.0

### ReferenceLine

0.2.0 removed `ReferenceLine`'s `color`, `icon`, `iconColor`, `layer`, `labelColor`,
`labelFontWeight`, and `lineType`. Reference lines use a fixed Spectrum 2 style. 0.4.0 added
`secondary` for a lighter line and `size`. See [ReferenceLine](../axis.mdx#referenceline).

```tsx
// Before
<ReferenceLine value={100} label="Target" color="gray-500" lineType="dashed" />

// After
<ReferenceLine value={100} label="Target" />
```
