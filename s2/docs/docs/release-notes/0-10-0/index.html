0.10.0

Donut is now an alpha component. This release also turns on animation by default and ships the package as ES modules for smaller bundles. It includes breaking changes; to update your app, see Upgrading to 0.10.0.

Breaking changes​

  • ESM only. The package ships as ES modules and requires Node >=20.19.0.
  • New peer dependency. react-aria-components ^1.14.0.
  • Entry points. Donut, DonutSummary, and SegmentLabel move to the package root. The pre-alpha entry point is renamed lab, and ChartActionBar is imported from lab.
  • Donut. startAngle and otherItemColor are removed.

Highlights​

  • Donut is alpha. Donut, DonutSummary, and SegmentLabel are imported from the package root and follow the alpha stage's stability rules. This release adds default ChartInspect and ChartPopover content, labels revealed on hover, size-based ring and label spacing, and many layout fixes. See Donut and Stages and lab.
  • Animation on by default. Lines, bars, donuts, and combos draw in when the chart mounts, and hover fades animate, following Spectrum 2 motion. Draw-in plays once per mount. When the user prefers reduced motion, draw-in is skipped and hover fades still play. See Animation.
  • Smaller bundles. The package no longer bundles its own copies of React Spectrum S2, React Aria, or Vega, so it adds about half as much to an app that already uses React Spectrum S2.
  • ChartActionBar (lab). A floating toolbar of actions for a clicked line point. See ChartActionBar.

Changed defaults​

  • Top and bottom legends align to the start of the chart instead of the center.
  • Donut segments are sorted largest first. Set sortOrder="data" to keep data order.
  • Chart props set to undefined fall back to their defaults.

Donut​

  • New semicircle variant: variant="semicircle". See Semicircle.
  • ChartInspect and ChartPopover show the segment's color, name, share, and value when they have no children. See Default content.
  • Hovering a segment shows its label, even when the label was hidden to avoid overlap. Hovering or clicking a label behaves like hovering or clicking its segment.
  • Ring thickness, label spacing, and donut size scale with the chart size, and side legends stay next to the donut.
  • Pie donuts have a 1px gap between segments.
  • Semicircle DonutSummary deltas sit inside the arc, and summary text that would truncate completely is hidden.
  • Fixed label overlap, tiny segments, and donuts growing or shifting on resize.

Bar​

  • BarDirectLabel follows each bar in stacked and dodged bars, and hides labels that overlap or don't fit. New overflow and dataKey props. See BarDirectLabel.
  • Better keyboard and screen reader support: dodged bars can be focused, focused bars and groups are described by their values, and Shift+Tab returns to the last focused bar.
  • Fixed highlightedItem (which now respects idKey), ChartInspect group highlighting, and short-number label formats.

Line​

  • Fixed hover with interactionMode="item", series highlighting, single-series lines, and interpolate="basis".
  • Fixed charts collapsing or flickering with fixed metric-axis ranges or when every series is hidden.
  • Fixed crashes with highlightedItem on a line without ChartInspect or ChartPopover, and with MetricRange.
  • Hovering a point at the chart edge no longer shifts the chart.

Axis and reference lines​

  • Reference lines outside the axis range no longer collapse the chart or flicker on hover.
  • A right axis lines up with a gridded left axis.

Lab charts​

  • Area: fixed a crash with highlightedItem, and band hover points sit on the band's upper edge.
  • Bullet: fixed hidden and missing targets, and value labels always use gray-900.
  • Combo respects the chart's animations and animationTypes.
  • Scatter: fixed highlightedItem, stroke set to a data field, and dotted outlines.
  • Trendline: dotted trendlines are visible again.

Performance and stability​

  • Charts render once when first displayed instead of twice, so they appear faster and no longer stay blank until hovered.
  • Hover animations stay smooth on charts with many points or series, and charts with many bars render faster.
  • Off-screen and idle charts do no animation work.
  • A chart with no children logs an error instead of throwing.
