# 0.11.0

This release raises the minimum Node version. To update your app, see [Upgrading](/react-spectrum-charts/s2/docs/docs/guides/upgrading#from-0100).

## Breaking changes

-   **Node 22.12 or later.** The S2 packages require Node `>=22.12.0`. The `vega-lite` peer dependency now installs a version that needs Node 22.12, so installs on Node 20 failed with strict engine checks.
